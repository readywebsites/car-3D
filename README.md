# Car Cinematic Website

Premium cinematic automotive frontend built with React + Vite + GSAP.

## 1. Install

```bash
npm install
```

## 2. Add videos

Put these four files inside `public/videos/`:

- exterior.mp4
- interior.mp4
- performance.mp4
- rear-hero.mp4

Optional poster:

`public/images/car-poster.jpg`

## 3. Run

```bash
npm run dev
```

Open the local URL shown by Vite.

## 4. Build

```bash
npm run build
```

## 5. Customize

Edit:

`src/config/carConfig.js`

You can change:

- car name
- section titles
- subtitles
- video filenames
- specifications
- CTA

## Video continuity

For the best result, generate all four videos with the same:

- car model
- car color
- wheels
- female model
- outfit
- environment
- lighting style

This keeps the four sections visually connected like one automotive commercial.
